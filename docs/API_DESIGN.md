# API Design

## 1. Conventions
- Base path `/api/v1`; JSON; OpenAPI generated by FastAPI is the source of truth.
- Auth: `Authorization: Bearer <JWT>`; tenant derived server-side.
- Errors: RFC 7807 problem details (`type`, `title`, `status`, `detail`, `request_id`).
- Pagination: `limit` + cursor. Dates: ISO 8601. Money: integer paise + `currency`.
- Every data response includes `data_source` and `as_of` so the UI can show MOCK labels.
- Rate limits per user/tenant; stricter on LLM endpoints; `429` with `Retry-After`.

## 2. Endpoint catalog (initial)
| Area | Endpoints |
|---|---|
| Health | `GET /health`, `GET /ready` |
| Auth/Me | `GET /me`, `GET /orgs`, `GET /orgs/{id}/members` |
| Accounts | `GET /seller-accounts`, `GET /profiles` |
| Dashboard | `GET /dashboard/summary?from&to`, `GET /dashboard/trends` |
| Campaigns | `GET /campaigns`, `GET /campaigns/{id}`, `GET /campaigns/{id}/metrics`, `GET /campaigns/compare` |
| Keywords | `GET /keywords`, `GET /search-terms`, `GET /keywords/wasted-spend` |
| Forecasts | `POST /forecasts`, `GET /forecasts/{id}` |
| Recommendations | `GET /recommendations`, `GET /recommendations/{id}`, `POST /recommendations/generate` |
| Approvals | `POST /recommendations/{id}/approve`, `POST /recommendations/{id}/reject`, `GET /executions` |
| Assistant | `POST /assistant/threads`, `POST /assistant/threads/{id}/messages` (SSE stream), `GET /assistant/runs/{id}` (trace) |
| Reports | `POST /reports`, `GET /reports/{id}/download` |
| Sync | `POST /sync` (admin), `GET /sync/runs` |
| Audit | `GET /audit-logs` (admin) |

## 3. Authorization matrix
Viewer: read. Analyst: read + generate recommendations + assistant. Admin/Owner: approve/reject, sync, audit. Deny by default.

## 4. SSE contract (assistant)
Events: `plan`, `tool_call`, `tool_result`, `token`, `final` (with evidence refs), `error`. Each event carries `run_id`.

## 5. Execution endpoint rules
`approve` records the decision only. Execution happens in a separate gated service and returns `409` if execution is disabled, the recommendation expired, or its `content_hash` changed since approval.
